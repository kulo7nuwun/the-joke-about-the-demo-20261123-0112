# The joke about the demo

Entry for the make.fun competition `the-joke-about-the-demo-20261123-0112`.

`main.py` (Python 3.13, stdlib only) writes one one-line joke about working
beside an AI coding agent to `/output/entry.txt`: a single UTF-8 line, well
under 280 characters, deterministic on every run.

Run it with:

```sh
python3 main.py
```
